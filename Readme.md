# Cloud-native Software-Defined Mobile Networks

This repository contains practical assignments and projects for the Cloud-native Software-Defined Mobile Networks course at Sharif University of Technology, Department of Electrical Engineering.

## Repository Structure

The repository is divided into two primary projects:
*   **[project_1-sdn-odl-virtual-networks](./project_1-sdn-odl-virtual-networks):** Focuses on building and managing virtual networks using Mininet, Open vSwitch (OVS), and the OpenDaylight (ODL) SDN controller. 
*   **[project_2-containers-and-docker](./project_2-containers-and-docker):** Explores containerization concepts from the ground up, including Linux network namespaces, custom container runtimes, and Docker application deployment.

Each project directory contains specific sub-folders for individual assignment problems, source code, execution scripts, and result screenshots.
